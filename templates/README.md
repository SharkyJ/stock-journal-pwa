# 시트 양식 (templates)

운용 중인 Google Sheets 3개 파일의 **구조·수식·입력 규칙만** 옮긴 양식입니다. 실제 거래·금액·시트 ID는 들어 있지 않고, 동작 확인용 **가상 샘플 데이터**만 들어 있습니다.

| 파일 | 원본 | 내용 |
|---|---|---|
| `주식일지_양식.xlsx` | 주식일지 (메인) | 총자산 · 국장투자 · 미장투자 · 현금투자 · 설정 · _거래집계(숨김) · App_* 8개(헤더만, 관심종목 샘플 1행) |
| `국장_주식일지_양식.xlsx` | 국장_주식일지 | 종목 탭 2개(NAVER, KODEX200 샘플) + 종목목록 |
| `미장_주식일지_양식.xlsx` | 미장_주식일지 | 종목 탭 1개(AAPL 샘플) + 종목목록 |
| `build_templates.py` | — | 위 3개 파일 생성 스크립트 (`pip install openpyxl` 후 `python3 templates/build_templates.py`) |

## 새로 시작하는 방법

1. Google Drive에 3개 .xlsx를 올리고 각각 **Google Sheets로 열기 → 파일 → Google Sheets로 저장**. 이름은 `주식일지`, `국장_주식일지`, `미장_주식일지`로 바꿉니다.
2. `주식일지` → `설정` 시트 B6·B7에 국장·미장 파일 URL을 붙여넣습니다.
3. **이름이 지정된 범위 확인** (데이터 → 이름이 지정된 범위): `FX_USDKRW`=설정!B5, `URL_KR`=설정!B6, `URL_US`=설정!B7.
   xlsx 가져오기에서 `URL_KR`·`URL_US`가 빠지는 경우가 있어(2026-10-21 확인), 없으면 직접 추가하세요.
4. `국장투자`!A5, `미장투자`!A5, `_거래집계`!A1(숨김 시트)의 `#REF!`에 마우스를 올려 **액세스 허용**(IMPORTRANGE 연결)을 누릅니다. 연결 후 합계·현금투자가 계산됩니다.
5. 샘플 데이터 지우기
   - 국장·미장 파일: 샘플 종목 탭의 9행부터 거래 행 삭제(또는 탭 자체를 내 종목으로 수정), `종목목록` A2부터 실제 탭 이름으로 교체
   - 메인 `현금투자`: B3 기준일, F7:F12·F20:F25 기준 예수금, 36행부터 입출금·환전 내역을 내 값으로 교체
   - `App_관심종목` 2행 샘플 삭제
6. 웹앱(이 저장소) 첫 화면에 3개 시트 URL을 입력해 연결합니다.

## 입력 규칙 (원본과 동일)

- **파란 글씨 칸만 직접 입력**, 나머지는 수식입니다.
- 종목 탭: B1 종목명, B2 티커(GOOGLEFINANCE 형식, `KRX:035420`, `NASDAQ:AAPL`), 8행 헤더, 9행부터 거래. 입력 열은 A 거래일자 · B 구분(매수/매도) · C 수량(**항상 양수**) · D 거래단가 · E 수수료/세금 · J 계좌구분 · K 메모, F–I는 수식(새 행은 위 행 수식 복사). **거래는 날짜순**(평단이 행 순서로 계산됨). 웹앱으로 입력하면 자동 처리됩니다.
- B3 현재가 수식의 `IFERROR(…, 숫자)`는 GOOGLEFINANCE 실패 시 쓰는 기본값입니다.
- `종목목록`: 국장투자·미장투자·_거래집계가 이 목록의 탭만 읽습니다. 웹앱의 "새 종목 탭"은 자동 추가, 시트에서 직접 탭을 만들면 여기에 이름을 추가하세요.
- 계좌 이름은 `현금투자` A열(원화 A7:A12, 달러 A20:A25)과 종목 탭 J열이 **정확히 같아야** 합니다. 환전은 원화·달러 계좌가 모두 있는 증권사 안에서만 일어나므로 두 구간의 이름도 같게 둡니다. 이름이 어긋나면 `현금투자` B32에 표시됩니다.
- 입출금·환전 내역(35행 헤더, 36행부터): 구분은 입금/출금/달러 매수/달러 매도. 원화는 입금·출금으로만, 달러는 달러 매수/매도로만 들어오고 나갑니다. 투자 원금(원화) = Σ입금 − Σ출금.
- 기준일(B3) 당일 행은 원금 이월분이라 예수금에는 더해지지 않습니다(기준 예수금 F열에 이미 포함). 기준일 이후 행·매매만 예수금에 반영됩니다.
- 기준 환율(B30) = 누적 달러 매수 원화 ÷ 달러(자동). 미장 원화 원금 = 달러 원금 × 기준 환율, 환차손익은 D31(미실현)·D32(달러 매도 실현)에 표시됩니다.

## 샘플 시나리오 (가상)

- 기준일 2026-01-02: 메리츠증권 ₩10,000,000·토스증권 ₩3,000,000 입금, 메리츠증권에서 $2,000 환전(₩2,700,000, 1,350원) → 기준 예수금 메리츠 ₩7,300,000 · 토스 ₩3,000,000 · 메리츠(USD) $2,000
- 이후: 토스증권 ₩1,000,000 추가 입금, 토스증권 $500 환전(1,352원), NAVER 매수·매수·일부 매도(메리츠), KODEX 200 매수(토스, 수수료 0.015%), AAPL 매수(메리츠)·매수(토스, 수수료 0.1%)·일부 매도(메리츠)

## 구조를 바꿀 때

시트 구조를 바꾸면 `build_templates.py`, 웹앱의 시트 파서와 `index.html` 데모 백엔드, 일간·주간 전망 예약 작업 프롬프트(App_전망·App_일간전망 열 변경 시)를 함께 맞춥니다.
