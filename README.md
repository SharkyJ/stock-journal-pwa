# 주식일지 (PWA)

Google Sheets 기반 주식일지(주식일지 / 국장_주식일지 / 미장_주식일지)를 휴대폰에서 기록·조회하는 웹앱입니다.
서버가 없고, 브라우저가 Google Sheets API에 **직접** 접속합니다. 이 저장소에는 시트 ID·계정·금액 등 개인 데이터가 들어 있지 않습니다.

## 기능
- **홈 대시보드**: 총자산(원화/달러 보기), 투자원금 대비 손익, 국장/미장 카드, 자산 배분(종목·국장/미장/예수금), 포트폴리오 점검(현금 비중·집중도·레버리지 비중·큰 손실 종목·환율 영향·데이터 이상), 목표가/손절가 알림, 수익률 상·하위
- **종목**: 보유/청산 목록, 정렬, 종목 상세(**총 누적손익** = 평가손익 + 실현손익, 누적 매수액 대비 % · **주가 차트**: 1일·1주 분봉 / 1개월~5년 일·주봉 캔들, 평단선·매수/매도 지점 표시 · 지표·계좌별 보유·매매 흐름 차트·거래 내역), 새 종목 탭 추가(기존 탭 복제)
- **거래 기록**: 매수/매도 입력 → 해당 종목 탭에 기록. 저장 전 정산금액·실현손익·거래 후 평단 미리보기, 과매도 차단, 과거 날짜는 날짜순 위치에 삽입(확인 후), 수정·삭제, 계좌별 수수료 자동 계산(토스 국장 0.015%, 토스 미장 0.1% + 매도 SEC Fee 0.00206%(최소 $0.01), 메리츠 Super365 2026-12-31까지 0% 후 미장 0.07% — 설정에서 계좌별 변경)
- **현금**: 계좌별 투자금·예수금, 입출금 기록(현금투자 시트 하단 '입출금 내역' 표)
- **분석**: 자산 추이(총자산 vs 원금, 수익률), 월별 실현손익, 매매 통계(승률·손익비), 매매 회고 + 전략 태그별 성과
- **전략** (주가 차트 서버 필요)
  - **신호**: 보유·관심종목의 단기·중기·장기 방향 점수(근거 표시), 전략 프리셋별 조회 — 추세추종(SuperTrend), 눌림목, 돌파, 평균회귀, 듀얼 모멘텀 — 와 최근 2년 과거 적중률, 리스크(트레일링 스탑·손절/목표가·목표비중·레버리지 변동성 손실)
  - **시장**: 코스피·코스닥·S&P 500·나스닥 100·필라델피아 반도체·VIX·원/달러 추세와 시장 국면(위험 선호/중립/위험 회피)
  - **전망**: Claude가 작성하는 일간 전망(평일 아침, `App_일간전망` 시트 — 오늘 전망·체크포인트)과 주간 전망(월요일 아침, `App_전망` 시트 — 단기·중기·장기)
  - **기록**: 새로 켜진 전략 신호(매수 신호·매도·경계·트레일링 스탑 이탈)를 `App_시그널` 시트에 자동 기록하고, 이후 5일·20일·현재까지 수익률과 전략별 실제 적중률 표시 (설정 → 기능 → 신호 자동 기록)
  - **도구**: 물타기·불타기(목표 평단 역산), 매도 시뮬레이션, 리스크 기반 포지션 사이징, 목표 비중 리밸런싱
  - 종목 상세의 **전략 분석** 카드: 지표 값, 프리셋별 상태와 5년 과거 적중률, 1주·1개월 예상 변동 범위, 재무·컨센서스(포워드 PER, 목표주가, 투자의견, 실적 발표일), 차트 지표 오버레이(이평선·SuperTrend·볼린저)
  - 신호는 조건 충족 여부일 뿐 매수·매도 권유가 아닙니다
- **보안**: Google 로그인(허용 계정 1개) + PIN/지문 잠금, 자동 잠금 시 화면 데이터 삭제

## 1. Google Cloud 설정 (최초 1회, 약 5분)
1. https://console.cloud.google.com → 새 프로젝트 생성
2. **API 및 서비스 → 라이브러리 → Google Sheets API → 사용**
3. **OAuth 동의 화면**: 사용자 유형 *외부* → 앱 이름 입력 → 범위는 건너뛰어도 됨 → **테스트 사용자에 시트 소유 Google 계정만 추가**
   - 게시 상태를 **테스트**로 유지하세요. 테스트 사용자 외에는 아무도 로그인할 수 없습니다.
   - 로그인 시 "Google에서 확인하지 않은 앱" 경고가 나오면 *계속*을 누르면 됩니다(본인이 만든 앱).
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID → 웹 애플리케이션**
   - 승인된 JavaScript 원본: `https://<깃허브아이디>.github.io` (로컬 테스트 시 `http://localhost:8000`도 추가)
   - 리디렉션 URI는 필요 없습니다.
5. 생성된 **클라이언트 ID**(`…apps.googleusercontent.com`)를 복사

> 테스트 모드 OAuth 토큰은 1시간 유효합니다. 앱은 토큰을 메모리에만 두며, 만료 시 "Google 계정 연결" 버튼을 한 번 누르면 됩니다.

## 2. GitHub Pages 배포
1. 새 저장소 생성 후 이 폴더의 파일 전체(`index.html`, `sw.js`, `manifest.webmanifest`, 아이콘, `.nojekyll`)를 루트에 업로드
2. **Settings → Pages → Branch: main / (root)** → 저장
3. `https://<아이디>.github.io/<저장소>/` 접속
4. 안드로이드 Chrome에서 **⋮ → 홈 화면에 추가(앱 설치)** → 앱처럼 전체화면 실행

**공개 여부**: 무료 GitHub Pages는 private 저장소라도 사이트 URL은 공개입니다. 이 앱은 코드만 공개되고 데이터는 없으므로 URL이 알려져도 Google 로그인 + 허용 계정 + 시트 공유 권한 없이는 아무것도 볼 수 없습니다.
URL 자체도 숨기고 싶다면 Cloudflare Pages + Cloudflare Access(이메일 OTP)처럼 접근 제어가 되는 호스팅을 쓰세요(OAuth 원본만 그 주소로 바꾸면 됩니다).

## 3. 앱 첫 실행
1. 주식일지 / 국장_주식일지 / 미장_주식일지 시트 URL, OAuth 클라이언트 ID, 허용할 Google 계정(시트 소유 계정) 입력
2. 6자리 PIN 설정 → (지원 기기) 지문 잠금 해제 등록
3. Google 계정 연결 → 데이터 로드
4. 홈의 **앱 전용 시트 만들기**를 누르면 메인 파일에 `App_매매계획`, `App_매매회고`, `App_자산추이`, `App_관심종목`, `App_전망`, `App_일간전망`, `App_시그널` 시트가 추가됩니다(헤더만 작성, 기존 시트 변경 없음)

첫 화면의 "데모 모드로 시작"으로 연결 설정 전에 먼저 둘러볼 수 있습니다(가상 데이터, Google 로그인·PIN 없이 바로 열림, 시트 접근 없음, 새로고침하면 초기화). 홈 상단의 "내 시트 연결"로 데모를 끝내고 연결 화면으로 이동합니다.

## 4. 주가 차트 서버 (선택, 약 10분)
> Worker 코드가 바뀌면(예: 전략 탭 추가 시 `/fund`, 2년·5년 일봉) 대시보드에서 `worker/chart-proxy.js`를 다시 붙여넣고 Deploy 하세요.

종목 상세 상단의 주가 차트는 Yahoo Finance 시세를 씁니다. 브라우저가 Yahoo를 직접 부를 수 없어(CORS) 무료 Cloudflare Worker 하나가 중계합니다. Worker로는 **종목 심볼과 기간만** 전송되고, 시트 데이터·Google 토큰은 전송되지 않습니다.

**대시보드에서 배포**
1. https://dash.cloudflare.com 가입(무료) → **Workers & Pages → Create → Create Worker** → 이름 `sj-chart` → Deploy
2. **Edit code** → 기본 코드를 지우고 [`worker/chart-proxy.js`](worker/chart-proxy.js) 내용을 붙여넣기 → Deploy
3. 앱 주소가 `https://sharkyj.github.io`가 아니면 **Settings → Variables → ALLOWED_ORIGINS**에 앱 주소(쉼표로 여러 개)를 넣기
4. 표시된 주소(`https://sj-chart.<계정>.workers.dev`)를 복사 → 앱 **설정 → 기능 → 주가 차트 서버 → 연결**에 붙여넣고 *연결 테스트* → 저장

**CLI로 배포**: `cd worker && npx wrangler deploy` (`wrangler.toml`의 ALLOWED_ORIGINS 확인)

- 엔드포인트: `/chart?s=심볼&r=기간` (1d·5d 분봉, 1mo·3mo·1y 일봉, 5y 주봉, 2y·5yd 지표·적중률용 일봉), `/fund?s=심볼` (재무·컨센서스 — 국장은 네이버 증권 추정 PER·EPS·목표주가·투자의견, 미장은 Yahoo 포워드 PER·목표주가 등, 6시간 캐시). 둘 다 비공식 API라 형식이 바뀌면 이 파일만 고치면 됩니다
- 티커 변환: `KRX:005930` → `005930.KS`(코스피, 못 찾으면 Worker가 `.KQ` 코스닥으로 재시도), `KOSDAQ:035720` → `035720.KQ`, `NASDAQ:MU` → `MU`, `NYSE:BRK.B` → `BRK-B`
- 갱신: 차트를 보고 있는 동안 장중 1분, 장 마감 후 10분(분봉) 간격. Worker도 30초~30분 캐시
- 무료 플랜 한도(일 10만 요청)와 비교하면 개인 사용량은 매우 작습니다
- 앱 CSP는 `https://*.workers.dev`만 허용하므로 다른 도메인(커스텀 도메인 포함)은 연결할 수 없습니다. 쓰려면 `build.py`의 connect-src를 바꾸세요

## 시트와의 연결 방식
| 앱 기능 | 읽기/쓰기 위치 |
|---|---|
| 요약(총자산·원금·예수금) | 주식일지 `총자산`(A열 '요약' 헤더 기준, 행/열 방향 자동 인식), `현금투자`, `설정!B5`(환율) — 읽기 |
| 보유 종목·거래 | 국장_/미장_주식일지의 각 종목 탭 `A1:K` — 읽기, 거래 입력은 **A–E, J–K열(입력칸)만** 기록. F–I 수식은 건드리지 않고, 수식이 없는 행에만 동일 수식을 채움 |
| 새 종목 | 기존 첫 종목 탭을 복제 → 입력칸 비움 → B1~B3(종목명·티커·현재가 수식) 설정 → 종목목록에 추가 |
| 입출금 | `현금투자` 시트 '입출금 내역' 표(헤더 '일자' 다음 행부터) — 직접 추가·삭제 |
| 매매계획·회고·자산추이 | `App_매매계획`, `App_매매회고`, `App_자산추이` |
| 관심종목 | `App_관심종목` (A 티커 · B 종목명 · C 시장 · D 메모 · E 추가일) — 앱에서 추가·삭제 |
| 신호 이력 | `App_시그널` (A 키(신호일\|티커\|전략\|신호) · B 신호일 · C 시장 · D 티커 · E 종목명 · F 구분 · G 전략 · H 신호 · I 근거 · J 가격 · K 기준 심볼 · L 기록시각) — 앱을 열 때 확정된 일봉 최근 10거래일을 보고 새 신호만 추가(장중 마지막 봉 제외, 같은 종목·전략·신호는 14일 안에 다시 기록하지 않음, 듀얼 모멘텀은 월말 기준). 쓰기 직전 A열을 다시 읽어 다른 기기와 중복 방지 |
| 일간 전망 | `App_일간전망` (A 작성일 · B 구분(시장/보유/관심) · C 티커 · D 종목명 · E 오늘 전망(강세/약강세/중립/약약세/약세) · F 요약 · G 체크포인트 · H 출처) — 평일 아침 Claude 예약 작업이 기록(30일 보관), 앱은 가장 최근 작성일만 표시 |
| 주간 전망 | `App_전망` (A 작성일 · B 구분(시장/보유/관심) · C 티커 · D 종목명 · E 단기 · F 중기 · G 장기(강세/약강세/중립/약약세/약세) · H 요약 · I 근거·이벤트 · J 출처) — Claude 예약 작업이 기록, 앱은 가장 최근 작성일만 표시 |

- 모든 쓰기 직전 시트를 다시 읽어 행 수가 바뀌었으면 중단합니다(다른 기기·시트에서 동시 편집 보호).
- 사용자 입력 텍스트가 `= + - @`로 시작하면 수식으로 실행되지 않게 텍스트로 저장합니다.

## 알려진 제약
- 요약 값은 IMPORTRANGE로 계산되므로 거래 기록 직후 몇 초~1분 늦게 반영될 수 있습니다(↻로 새로고침).
- 현재가·환율은 GOOGLEFINANCE(최대 약 20분 지연) 값입니다.
- 주가 차트는 Yahoo Finance의 비공식 차트 API를 씁니다(국장 약 20분 지연). Yahoo가 응답 형식을 바꾸면 `worker/chart-proxy.js`만 고치면 됩니다. GOOGLEFINANCE 과거 시세는 Google 정책상 Sheets API로 읽을 수 없어 차트 데이터로 쓸 수 없습니다.
- 미장 원화 환산: 평가금액·예수금은 실시간 환율, 투자 원금은 `현금투자` 기준 환율(B30)을 적용하므로 원화 총 손익에 환차손익이 포함됩니다.
- PIN/지문은 이 기기의 화면 잠금입니다. 데이터 보호의 핵심은 Google 계정 인증과 시트 공유 권한입니다.

## 자산 추이 자동 기록 (선택)
앱은 열 때마다 오늘 값을 기록합니다. 앱을 열지 않은 날도 기록하려면 `snapshot.gs`를 메인 시트의 Apps Script에 붙여넣고 `installTrigger`를 한 번 실행하세요.

## 보안 설계 요약
- 서버 없음, 토큰은 메모리에만 저장(로컬 저장 안 함), 시트 데이터는 브라우저 저장소에 저장하지 않음
- Service Worker는 앱 파일만 캐시하고 Google API 응답은 캐시하지 않음
- CSP: 인라인 스크립트 SHA-256 고정, 외부 스크립트는 Google 로그인만 허용, 통신은 Google API 도메인과 차트용 `*.workers.dev`만 허용
- 차트 Worker는 허용된 앱 주소(Origin)에서 온 요청만 받고, 받는 값은 심볼·기간뿐이며 쿠키·토큰을 보내지 않음(`credentials: omit`, referrer 미전송)
- 잠금 시 화면 데이터 삭제 후 해제 시 다시 로드, PIN 5회 오류부터 대기 시간 증가
- referrer 미전송, 검색엔진 색인 차단
