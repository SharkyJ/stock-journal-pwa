# 매도법 1차 구현

전략 하위 탭 순서: 매도법 → 신호 → 기록 → 도구.

## 저장과 실행

설정의 앱 전용 시트 만들기로 `App_매도규칙`(종목키, 설정 JSON, 수정시각), `App_매도이력`(이벤트키, 종목키, 평가 JSON, 기록시각)을 추가한다. 기존 시트의 열이나 데이터는 수정하지 않는다. 데모에서도 같은 저장 경로를 사용한다.

앱이 열리고 잠금 해제된 동안 설정된 보유 종목의 일봉을 요청한다. 확정 일봉으로만 평가하고 최초 상태와 이후 상태 전환을 저장한다. 규칙 버전·보유 회차·평가일·상태를 이벤트 키에 포함해 중복을 억제한다. 설정 변경도 이력에 남는다. 자료 부족·지연은 신호 이력으로 저장하지 않는다. 화면에는 최근 100건을 표시한다.

## 기법 정의

- 손실제한: 고정가 우선, 미설정 시 현재 평단 × (1−손절률). 종가가 기준가 이하면 충족, 위쪽 2% 이내면 근접.
- 2/3 수익보호: 현재 평단 + (보유 후 최고가−현재 평단) × 2/3. 최고 수익률 5%부터 활성화한다. 매수 당일 고가는 매수 이전일 수 있어 제외한다. 보유 시작 이전부터 조회할 수 없으면 데이터 부족으로 표시한다.
- 이동평균선: 20/60개 확정 종가의 단순평균 아래에서 마감하면 충족한다. 신규 하향 돌파와 기존 하회 상태를 근거에서 구분한다.
- 봉 패턴: 1.5% 이상 하락 갭, 3연속 음봉, 직전 양봉 몸통 중간 이하로 마감하는 음봉 중 하나면 충족한다. CREST 복합 점수를 재현하지 않는다.

부분매도는 보유 회차를 유지한다. 추가매수로 평단이 바뀌면 기준가를 재계산하고 평가 이력에 당시 평단을 보존한다. 전량 매도 후 재진입하면 설정 재저장이 필요하다. 모든 기법을 끄고 저장하면 평가를 중단한다.

## 한계

앱 종료 중 예약 실행·푸시, 분할매도 비율 설정, 매물대·추세선·가치·경기 기법은 후속 범위다. 시장 휴일을 고려한 자료 신선도 대신 7일 경과를 지연 기준으로 사용한다. 주식 분할 등 원가와 시세의 조정 기준은 데이터 제공 경로에 의존한다. 시세 제공자의 장중 상태가 부정확하면 마지막 봉 완결성도 영향을 받는다. 실시간 손절 감시나 체결 보장이 아니다.
