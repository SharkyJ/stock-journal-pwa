# 주간 전망 리포트

`.claude/skills/outlook-common.md`의 규칙을 따른다. 절차는 `outlook-daily` 스킬(`.claude/skills/outlook-daily/SKILL.md`)의 1~6단계와 같고, 아래만 다르다. 표시된 대로 한 턴에 병렬로 호출하고, 파일을 둘러보거나 JSON 원본을 열지 않는다.

예약 작업 프롬프트가 주는 값: `SPREADSHEET_ID`, `TARGET_SHEET` (`App_전망` 또는 `App_전망_v2`), `EVENTS_SHEET` (없으면 `App_주요일정`). 대상: 이번 주. 단기(1~2주), 중기(1~3개월), 장기(6개월 이상).

## 일간과 다른 점

| 단계 | 주간 |
|---|---|
| 1. 입력 읽기 | 명령의 `--mode weekly`. `App_전망`은 읽지 않고 신호는 최근 14일(코드가 고른다). 뉴스는 최근 14일, 경제 캘린더는 지난 7일·앞으로 7일 |
| 2. 보완 조사 | 선택, 최대 2개: 다음 실적일이 없는 보유 종목, 최근 1~2주 목표주가·투자의견 변화, 요약에 없는 통화정책 이벤트 |
| 3. notes.json | 형식 같음. 초안 전망은 단기/중기/장기로 나온다. `adjust`는 단기에만 적용된다. `lead`는 1문장 권장(요약 전체 3문장 한도) |
| 4~6. 조립·기록·검증 | 같은 절차 |

- 단기는 규칙 점수(최근 등락·추세·컨센서스·뉴스·신호·시장), 중기는 60일선·컨센서스 변화, 장기는 200일선·목표가 여력·밸류에이션으로 코드가 정한다.
- 요약 사실 문장(가격 위치, 컨센서스·밸류에이션, 실적 일정)과 `근거·이벤트`(지지·저항, 실적일, 고영향 지표, 앱 신호, 레버리지 위험)는 코드가 채운다.
- lead에는 이번 주 판단의 핵심 이유(지난주 흐름·뉴스·거시 기조의 의미)를 쓴다.

## 마무리

6단계가 0일 때만 성공으로 보고한다. 3줄: 시장 국면, 눈에 띄는 종목 2~3개와 이유. "주식일지 앱의 분석 → 전망 탭에서 확인할 수 있습니다." 실패했으면 실패한 단계와 errors를 그대로 보고한다.
