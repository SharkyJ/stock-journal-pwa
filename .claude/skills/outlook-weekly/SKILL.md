# 주간 전망 리포트

`.claude/skills/outlook-common.md`의 규칙을 따른다. 절차는 `outlook-daily` 스킬(`.claude/skills/outlook-daily/SKILL.md`)의 1~8단계와 같고, 아래만 다르다. 표시된 대로 한 턴에 병렬로 호출하고, 파일을 둘러보거나 JSON 원본을 열지 않는다.

예약 작업 프롬프트가 주는 값: `SPREADSHEET_ID`, `TARGET_SHEET` (`App_전망` 또는 `App_전망_v2`), `EVENTS_SHEET` (없으면 `App_주요일정`). 대상: 이번 주. 단기(1~2주), 중기(1~3개월), 장기(6개월 이상).

## 일간과 다른 점

| 단계 | 주간 |
|---|---|
| 1. 입력 읽기 | `'App_전망'` 은 읽지 않는다. `signals`는 최근 14일 |
| 2. input.json | `"mode": "weekly"`, `weekly`는 빈 배열 |
| 3. 수집 | 같은 명령. 뉴스는 최근 14일, 경제 캘린더는 지난 7일·앞으로 7일이 요약된다 |
| 4. 보완 조사 | 병렬 웹 검색 최대 3개: 경제 캘린더가 `ok`면 지표 일정은 검색하지 않는다. 요약에 없는 통화정책 이벤트(연준·한은 발언), 다음 실적일이 요약에 없는 보유 종목, 최근 1~2주 목표주가·투자의견 변화 |
| 5. analysis.json | 아래 형식. `summary` 2~3문장(420자 이내, 마침표 3개 이하), `event` 300자 이내, `src` 최대 3개 |
| 6~8. 조립·기록·검증 | 같은 절차(`build_rows.py`에 `--calendar`·`--events`, 주요일정 기록 포함). 재조회는 작성일·구분·티커·종목명·단기를 대조 |

```json
{"rows": [
  {"key": "market", "s": "중립", "m": "약강세", "l": "강세", "summary": "2~3문장",
   "event": "이번 주 일정·리스크(날짜 포함)", "nums": ["M1", "M5"], "src": ["N3", "W1"]},
  {"key": "NASDAQ:MU", "s": "약강세", "m": "강세", "l": "강세", "summary": "...",
   "event": "다음 실적 2026-12-24 · 앱 신호: 11/03 돌파 매수 신호", "nums": ["T12"], "src": ["N14"]}
]}
```

- 해석 체크리스트의 주간 필수 항목(컨센서스 변화, 밸류에이션 포함)을 확인한다.
- 시장 행 `event`에는 이번 주 고영향 지표(C..)를 날짜와 함께, 지난주 발표 결과와 거시 기조를 요약에 쓴다. 종목 행은 실적 일정·직전 분기 결과(E..)를 인용한다.
- 최근 14일 앱 신호가 있는 종목은 신호가 뉴스·실적과 맞는지 보고 `event`에 "앱 신호: 날짜 전략 신호"로 적는다.
- 레버리지·인버스 ETF는 기초자산 기준으로 전망하고 변동성 손실 위험을 짧게 언급한다. 일반 ETF는 구성 업종·지수 흐름 기준.

## 마무리

8단계가 0일 때만 성공으로 보고한다. 3줄: 시장 국면, 눈에 띄는 종목 2~3개와 이유. "주식일지 앱의 분석 → 전망 탭에서 확인할 수 있습니다." 실패했으면 실패한 단계와 errors를 그대로 보고한다.
